# 강의 PPT PDF 변환기 — macOS 로컬 웹앱

MP4/MOV/MKV를 웹 화면에 올리면 흰 배경 슬라이드를 추출하고 `원본 영상명.pdf`를 내려받습니다. 영상은 외부 서버로 전송되지 않습니다. 설치할 때는 패키지 다운로드를 위해 인터넷이 필요합니다.

## 실행

1. ZIP을 압축 해제합니다.
2. Python 3.11 이상과 Tesseract를 설치합니다. Python은 https://www.python.org/downloads/macos/ 에서 설치할 수 있습니다. Homebrew가 설치되어 있다면 터미널에서 `brew install tesseract`를 실행하세요. Homebrew 안내: https://brew.sh
3. `run.command`를 더블 클릭합니다. 첫 실행 시 전용 `.venv` 환경과 필요한 패키지를 설치합니다.
4. 브라우저에서 http://127.0.0.1:5050 에 접속합니다. 영상을 선택하고 **PDF 변환 시작**을 누릅니다.
5. 완료되면 다운로드가 시작됩니다. 자동 다운로드가 차단되면 **PDF 다운로드**를 누릅니다.
6. 종료하려면 실행 중인 터미널 창에서 Control+C를 누릅니다.

실행 권한 문제 또는 macOS 확인 창이 나타나면 프로젝트 폴더에서 터미널을 열어 `bash run.command`로 실행할 수 있습니다.

### 수동 실행

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

5050 포트를 이미 쓰고 있다면 `PORT=5051 bash run.command`로 실행하세요. Python/Tesseract를 업데이트한 뒤 문제가 생기면 `.venv` 폴더를 지우고 다시 실행하세요. 가상환경이나 다른 Mac으로 이동한 폴더에는 재설치가 필요합니다.

## 처리 방식

- 0.2초 간격으로 화면을 검사합니다. 원본 해상도로 PNG를 저장하고 PDF로 묶습니다.
- 화면 변화 전까지 마지막으로 확인된 안정 프레임을 계속 갱신합니다. 큰 변화가 감지되면 직전 안정 프레임을 후보로 확정합니다. 마지막 슬라이드도 처리합니다.
- HSV 흰색 비율 42%, 중앙 흰색 비율 50%, 최소 내용 비율 0.6%로 흰 배경 PPT를 판별합니다.
- 오른쪽 아래 가로·세로 각각 마지막 16% 영역을 확대하고, 세 가지 전처리와 세 가지 Tesseract 레이아웃 모드로 숫자를 읽습니다. 신뢰도 25 이상, 1~300만 허용하고 반복 검출 횟수와 신뢰도로 선택합니다.
- 번호가 없으면 먼저 등장한 순서로 PDF 앞에 둡니다. 번호가 있으면 숫자 오름차순으로 정렬합니다.
- 같은 번호는 어두운 픽셀과 채도 높은 색상 픽셀의 내용량 점수가 높은 버전을 선택합니다. 번호 없는 페이지는 SSIM 0.91 이상이면 중복으로 보고 내용량을 비교합니다.

## 조정 및 한계

이 로직은 흰색 비율과 이미지 유사도를 사용하는 휴리스틱입니다. 흰 벽의 인물 화면을 PPT로 오인하거나, 사진·색 배경 PPT를 누락할 수 있습니다. 화면 전체가 슬라이드에 가까운 영상에 적합하며, 자동 슬라이드 영역 자르기는 하지 않습니다. 영상의 여백·플레이어 UI·얼굴 창도 캡처에 포함될 수 있습니다.

`processor.py`의 `is_white_slide()` 비율을 낮추면 후보가 늘어납니다. `CHANGE_THRESHOLD`를 높이면 작은 페이지 변화도 더 잘 잡지만 필기 변화가 페이지 변화로 잡힐 수 있습니다. `STABLE_THRESHOLD`, `MIN_STABLE_FRAMES`, `SAMPLE_INTERVAL`로 안정 판별과 검사 간격을 조절할 수 있습니다. 아주 비슷한 두 슬라이드, 느린 페이드 전환, 빠른 필기 직후의 전환은 누락 또는 중복이 생길 수 있습니다. 0.2초 간격이므로 실제 전환 바로 전 프레임과 최대 수백 ms 이상 차이가 날 수 있고, 안정 조건이 성립하지 않는 매우 짧은 슬라이드는 제외됩니다.

페이지 번호 위치가 다르면 `detect_page_number()`의 crop 범위를 바꾸세요. 300장 이상이면 `MAX_PAGE_NUMBER`를 늘리세요. OCR은 틀릴 수 있으며 같은 번호로 잘못 읽힌 서로 다른 페이지는 병합될 수 있습니다. 번호 없는 서로 비슷한 페이지도 병합될 수 있습니다. 필기량 점수는 의미를 이해하지 않으므로 노이즈가 많은 화면을 선택할 수도 있습니다. 중요한 자료는 결과 PDF를 확인하세요.

확장자가 같아도 OpenCV가 지원하지 않는 코덱, 손상된 파일, DRM 영상은 처리하지 못할 수 있습니다. 이때 H.264 MP4로 다시 인코딩해 시도하세요. OCR은 후보당 최대 9회 실행하므로 긴 영상은 오래 걸릴 수 있습니다. 원본 크기의 업로드 디스크 공간과 추출 이미지/PDF를 위한 추가 여유 공간이 필요합니다. 최대 업로드는 8GB, 실행 중/대기 중 작업은 합계 3개이며 순차 처리합니다.

## 파일 정리와 보관

작업별 임의 ID 폴더를 운영체제의 임시 폴더에 만듭니다. 원본 파일명은 다운로드 이름으로만 사용합니다. 원본 영상은 성공/실패와 관계없이 작업 종료 시 삭제하고 PNG는 처리 종료 시 삭제합니다. 실패한 PDF도 삭제합니다. 결과 PDF는 완료 또는 최근 다운로드 후 1시간 경과 시 1분 간격으로 정리하고, 정상 앱 종료 시 전체 작업 폴더를 삭제합니다. 업로드 도중 연결이 끊기거나 저장에 실패해도 해당 작업 폴더를 정리합니다.

강제 종료·전원 차단 시 정리 코드가 실행되지 않을 수 있습니다. 남은 자료는 macOS 임시 폴더의 `ppt-web-*` 폴더에 있을 수 있습니다. 앱을 종료한 상태에서 해당 폴더를 삭제할 수 있습니다. 서버 재시작 시 이전 작업 링크는 복원되지 않습니다.

로컬 개인 사용용 Flask 개발 서버입니다. `127.0.0.1`에만 연결되며 외부 공개 서버로 사용하지 마세요. 실행 중인 터미널 창을 닫으면 처리가 중단됩니다.

## 구성

- `app.py`: 업로드, 작업 상태, 순차 처리, 다운로드, 파일 정리
- `processor.py`: 슬라이드 감지·OCR·중복 선택·PDF 생성
- `templates/index.html`, `static/style.css`, `static/script.js`: 한국어 웹 화면
- `requirements.txt`: Python 의존성
- `run.command`: macOS 실행 스크립트

## 검증 범위

제작 환경(macOS, Python 3.14)에서 실제 Tesseract를 사용한 합성 MP4 영상으로 흰 배경 판별, 전환 전 안정 프레임 추출, 마지막 슬라이드 처리, 번호 없는 페이지 우선 배치, 숫자순 정렬, 필기가 추가된 동일 번호 페이지 선택과 PDF 생성을 확인했습니다. Flask 테스트 클라이언트로 업로드·상태 조회·다운로드, 한글/공백/#이 포함된 다운로드 이름, 잘못된 확장자 거부, 외부 Origin 거부, 원본 영상/중간 이미지 삭제를 확인했습니다. Python 문법과 실행 스크립트 문법 검사도 통과했습니다. 실제 사용자의 강의 영상 및 모든 MOV/MKV 코덱, Safari/Finder 더블클릭 동작은 별도 실기 검증하지 않았습니다.
